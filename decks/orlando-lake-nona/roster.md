same outline, each needs:

- Position (and age / height if it should appear on the slide)

- Two to four named interested programs for the spotlight chips

since the deck was cut (Jose Brito 7 → 11, Sam Bassin 17 → 18, Eduardo Marquez
Cerezo 5 → 6), plus Anthony Allotta's current row, before the aggregate slides
